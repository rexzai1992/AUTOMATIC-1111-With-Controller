SF3D setup notes

The FastAPI wrapper is custom because the official project ships command-line and Gradio entry points, not this REST contract.

  1. Request access to stabilityai/stable-fast-3d.
  2. Create a read token in Hugging Face settings.
  3. Run %USERPROFILE%\miniconda3\condabin\conda.bat activate sf3d, then huggingface-cli login.
  4. Start C:\AI\stable-fast-3d\start_sf3d_api.bat.

Windows support in the official SF3D repository is experimental and its texture/UV extensions require Visual Studio 2022 C++ Build Tools.

Troubleshooting

model_loaded=false: inspect the model_error returned by SF3D /health. Common causes are missing Hugging Face access/login or unbuilt C++/CUDA extensions.

An externally started healthy service is shown as unmanaged. The controller deliberately refuses to stop it because it does not own that PID.
